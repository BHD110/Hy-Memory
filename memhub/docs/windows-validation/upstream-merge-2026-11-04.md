## Windows 单独适配与既有修复保留

- Windows 数据库备份/恢复使用可刷盘的读写文件句柄，跳过 Windows 不支持的目录 fd fsync；保留验证后原子替换。
- 活跃模型检索视图禁用生成图存储，避免只读客户端再次打开写入客户端已经占用的 Kuzu 数据库。
- 测试隔离入口兼容 Windows 的 USERPROFILE，仍拒绝真实用户 HOME/数据目录；异步资源关闭测试使用有界等待。
- 保留旧 Windows 版已经发出的 SDK 请求编号；升级后查询旧回执，自动重试使用持久化新编号。旧界面的手动重试 API 保留以兼容现有前端。
- 保留 OpenCode Go 会话请求头、Windows ACL 权限存储、文件导入、已有记忆独立入队和显式原文读取 shadow 备份等修复。
- 原文读取修补脚本现验证 2.0.13 的代码结构；构建时在安装 SDK 后重施。单独重装 SDK 后同样需运行该脚本。
